# /draft · 正式写作（Formal Writing）

**用途**：投诉信、申诉信、申请信、婉拒信、谈判邮件等成文文件。
**引擎**：`wiki/playbooks/p3-formal-writing/`
**配套**：`wiki/scenarios/sc9-live-service/`（投诉与客服交锋的现场面）

## 流程（按序执行）

### 1. 定类型与对象
先确定五类之一：**投诉**（要求纠正/退款）、**申诉**（推翻某个决定）、**申请**（请求给予机会/资源）、**婉拒**（拒绝邀约/要求）、**谈判**（争取条款）。
再确定收件人是谁、他的裁量权有多大、他不办你的事会损失什么。对象决定语气上限与升级空间。

### 2. 收集要素
开写前把料备齐，缺就向用户要：
- 事实：时间、地点、单号/账号、金额、经手人
- 已尝试：哪天通过哪个渠道联系过谁、得到什么答复
- 证据：收据、截图、往来记录、合同条款
- 诉求：**一个**具体的、可核验的要求（退多少钱、多少天内、退到哪）

### 3. 六件套结构（缺一即废稿）
结构标准来自 `wiki/playbooks/p3-formal-writing/`：

1. **发件人**（sender）：姓名、联络方式，必要时地址
2. **收件人**（recipient）：机构、部门、负责人，尽量到人
3. **日期**（date）：YYYY-MM-DD
4. **主题**（subject）：事由 + 编号，一句话让人知道信要办什么
5. **正文**（body）：事实经过 → 问题与影响 → 已做的努力，按时间线，不抒情
6. **诉求**（demand）：一个具体要求 + 明确期限 + 逾期后果（见升级阶梯）

### 4. 升级阶梯（escalation ladder）
写第一封信时就要想好整条梯子（参考 `wiki/playbooks/p3-formal-writing/` 与 `wiki/scenarios/sc9-live-service/`；马来西亚场景的机构名为 Practice heuristic，发信前核实现行渠道）：

| 阶梯 | 对象 | 动作 |
|------|------|------|
| 第 1 级 | 商家/机构自己的客服或投诉部门 | 正式信件 + 期限（常用 14 天）+ 保留升级权利 |
| 第 2 级 | 监管机构/消费者组织（如马来西亚的消费人仲裁庭 Tribunal Tuntutan Pengguna、相关部委或行业协会） | 提交投诉，附第 1 级往来记录 |
| 第 3 级 | 小额索赔/法律途径，或公开评价（最后手段） | 仅在前两级失败后，且事实与证据过硬 |

分寸：第 1 级信里**提及**「如未解决将向有关方面投诉」即可；不要在第一封信就把第 3 级拍在对方脸上，除非杠杆明显不足。

### 5. 语域按文化
- 对政府机构/马来语环境：马来语正式语体，礼节层级高 → `wiki/cultures/cu1-malaysia-malay/`
- 对华人商号：敬语与人情并重，先礼后兵 → `wiki/cultures/cu2-malaysia-chinese/`
- 对印度裔商家/社群：称谓与节日礼节 → `wiki/cultures/cu3-malaysia-indian/`
- 高低语境与直接程度 → `wiki/cultures/cu4-cross-cultural-general/`
- 用什么语言写（BM / EN / 中文）本身就是姿态 → `wiki/cultures/cu5-codeswitching/`
- 求职申请类附场景细节 → `wiki/scenarios/sc8-job-interviews/`
- 说服结构（先共识后诉求）→ `wiki/concepts/c2-persuasion-influence/`；克制的修辞 → `wiki/concepts/c12-rhetoric-storytelling/`

### 6. 填骨架
用下面的骨架成稿（【】为槽位，按事实填入后删除括注）：

```text
【发件人姓名】
【联络方式：电话 / 邮箱 / 地址（按需）】

【收件人：机构名称，部门，负责人姓名/职衔】
【机构地址】

【日期：YYYY-MM-DD】

主题：【事由 + 编号，例：关于订单 A1234 退款被拒的正式投诉】

尊敬的【负责人/部门】：

一、事实经过
我在【YYYY-MM-DD】通过【渠道】购买/办理了【产品或服务，编号】，
金额【RM 数额】。【按时间线补 1-3 句关键事实。】

二、问题与影响
【发生了什么问题，对我造成什么损失/不便。】
我已于【YYYY-MM-DD】通过【渠道】联系【对象】，得到的答复是【原文/概述】。

三、诉求
请在【期限，例：本函日期起 14 天】内【一个具体、可核验的要求，
例：将 RM 数额全额退回至原支付方式】。

四、随附证据
1.【收据/订单截图】  2.【往来记录】  3.【其他，编号列出】

五、后续安排
如期限内未获解决，我将向【下一级：监管机构/消费者组织】提出投诉，
并保留采取进一步措施的权利。

此致
敬礼

【姓名/签名】
【联络方式】
```

婉拒信与申请信复用同一六件套：把第三节「诉求」换成「决定与理由」或「请求与理由」，升级阶梯一节对内文书可省。

### 7. 发出前检查
- 六件套齐：发件人、收件人、日期、主题、正文、诉求，一项不缺
- 诉求具体可核验（有数额、有期限、有去向）
- 每个事实陈述有证据对应；没有证据的删掉或改为「据我理解」
- 语气 firm not rude：批评行为，不贬损人格
- 升级表述与实际计划一致，不虚张声势
